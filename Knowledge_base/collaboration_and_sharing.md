# Collaboration & Sharing

Work better as a team using InsightEdge’s built-in sharing and access control features.

## Share a Dashboard
- Open any dashboard and click **“Share”**
- Enter the teammate's email
- Choose their role: Viewer / Editor / Admin

## Permissions
- **Viewer**: Can view only
- **Editor**: Can edit dashboard layout
- **Admin**: Can manage permissions and delete

All actions are tracked in the **Activity Log**.
