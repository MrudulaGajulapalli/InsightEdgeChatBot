# about API Introduction

InsightEdge provides a REST API to access, manage, and push data programmatically.

## Getting Started
1. Go to **Settings > Developer Tools**
2. Generate an API key
3. Read our API docs at: `https://insightedge.io/api-docs`

### Sample Request
```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://insightedge.io/api/v1/metrics
