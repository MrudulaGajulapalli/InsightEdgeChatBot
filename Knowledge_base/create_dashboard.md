# How to Create a Dashboard

Follow these steps to create your first dashboard in InsightEdge:

1. Navigate to **Dashboards > New Dashboard**
2. Choose a layout or start from scratch
3. Drag widgets (like charts, tables, metrics) into the canvas
4. Connect each widget to a data source
5. Configure filters, refresh rates, and alerts
6. Click **Save & Publish**

You can later edit or duplicate dashboards anytime from the Dashboard Manager.
