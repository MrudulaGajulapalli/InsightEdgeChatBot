# Common Issues & Fixes

### ❌ Data not updating
- Check if your data source is live and accessible.
- Verify refresh interval settings on your dashboard.

### ❌ Widget shows "No Data"
- Ensure correct column mappings and filters are set.
- Confirm that data exists for the selected time range.

### ❌ API returns 401 Unauthorized
- Regenerate your API key under **Settings > Developer Tools**.
